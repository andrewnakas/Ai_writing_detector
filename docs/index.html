ℹ️ About This Detector

This tool analyzes text for patterns commonly found in AI-generated content, based on Wikipedia's comprehensive guide: Signs of AI Writing.

Wikipedia editors have identified these patterns through analyzing thousands of instances of AI-generated text. The detector evaluates your text across multiple categories:

  • Language and Tone: Grandiose language, promotional phrasing, editorial commentary
  • Structural Patterns: Rule of three, negative parallelism, excessive formatting
  • Content Issues: Vague attribution, hallucinated citations, generic filler
  • Technical Clues: Markdown artifacts, placeholders, chatbot disclaimers

⚠️ Important Disclaimers

  • Not 100% Accurate: This detector identifies patterns commonly found in AI writing, but these patterns can also appear in human writing.
  • Context Matters: Some writing styles (e.g., marketing copy) naturally use patterns that AI also uses.
  • Educational Purpose: This tool is designed for education and awareness, not for definitive AI detection.
  • Evolving Patterns: AI writing patterns change as models improve. This tool tracks Wikipedia's latest documentation.

📚 How It Works

  1. Daily Updates: GitHub Actions automatically fetches the latest Wikipedia article every day
  2. Pattern Matching: The detector uses regex patterns and keyword analysis to identify signs
  3. Weighted Scoring: Each sign is weighted by severity (high/medium/low) and frequency
  4. Category Analysis: Results are grouped by category for comprehensive insights
  5. Contextual Highlighting: Matched patterns are highlighted with context and citations
