# AI Writing Detector → GPTTrace

This project has moved to **[GPTTrace](https://gpttrace.com/)**.

GPTTrace is a free AI detector for text, images, audio and video. Everything runs in your browser, and nothing you check is uploaded. The original Wikipedia "Signs of AI writing" checks live on as part of its [AI text detector](https://gpttrace.com/ai-text-detector/), alongside a neural model. Results and methods are on the [methodology page](https://gpttrace.com/methodology/).

The old GitHub Pages site (`andrewnakas.github.io/Ai_writing_detector`) now redirects to gpttrace.com. The original code is in this repository's git history.
